# 投资界融资周报检索与总结

## 目标

根据用户给定的开始日期、结束日期、赛道/关键词和企业地域口径，从投资界“每周投融资事件”页面抓取候选事件，并输出结构化清单或摘要。优先使用投资界原文；对于金额、轮次、领投方和全部投资方，必须回到单篇新闻页核验，不能只依据列表标题。

## 工作规则

1. 将日期区间拆分为覆盖区间的周一日期，访问 `https://www.pedaily.cn/weeklyinvest/YYYYMMDD/`。主页 `https://www.pedaily.cn/weeklyinvest/` 只代表当前周；历史周页面可通过列表中的“往期事件”链接发现。
2. 提取每周页面中的事件标题、日期、时间和文章链接，合并后按文章链接及“企业+披露日期+轮次”去重。
3. 对每个候选事件打开投资界新闻页，抽取：企业简称、业务描述、融资披露日期、轮次、金额、领投方、全部投资方、资金用途和来源链接。标题或正文没有披露的字段填写“未披露”，不得推断。
4. 按用户赛道定义过滤。默认重点词：`具身智能|人形机器人|物理AI|商业航天|航空航天|军工|低空经济|eVTOL|无人机|汽车|汽车零部件|自动驾驶`。赛道边界项目单独标注“待核验”，不要静默纳入或排除。
5. 对“近日完成”“近期完成”等相对日期：把文章发布日期作为“披露日期”，同时在备注中保留原文表述；如果用户要求融资完成日期，必须另列“完成日期”并标注其来源。
6. 公开页面是新闻线索而非完整创投数据库。输出必须包含来源链接、检索区间、抓取时间和口径说明；金额和投资方存在多篇报道冲突时保留冲突并标注，不自行调和。

## 输出格式

默认输出 Excel，主表列顺序：

`融资披露日期、企业简称、企业业务描述、赛道、交易轮次、融资金额、领投方、全部投资方、资金用途、来源链接、核验备注`

按披露日期从新到旧排序。若用户只要摘要，先给事件总数和分赛道统计，再给按日期倒序的事件表。

## 工具路由

- 需要快速抓取周列表：运行 `scripts/pedaily_weekly.py`。
- 需要高可信字段、处理相对日期、判断中国大陆注册企业或解决重复事件：使用网页搜索/打开原文，必要时查公司官网或权威媒体交叉验证。
- 需要生成 `.xlsx`：使用 `xlsx` skill 的格式要求，至少冻结首行、启用筛选、设置换行和来源列，不把链接或正文转成图片。

## 边界与合规

- 不绕过登录、验证码、付费墙、频控或反爬措施；遇到访问限制，改用网页搜索或公开原文链接。
- 不把上市公司定增、股票回购、银行授信、订单、战略合作、基金设立误标为一级市场融资。
- 不把海外主体纳入“中国大陆企业”清单，除非用户明确允许；港澳台和境外企业单独标注。

详细字段与判定规则见 [references/schema.md](references/schema.md)。
