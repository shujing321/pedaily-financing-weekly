# 字段和口径

## 主表字段

| 字段 | 规则 |
|---|---|
| 融资披露日期 | 投资界文章发布日期；格式 YYYY-MM-DD |
| 企业简称 | 以原文为准；品牌名与工商主体不同的，在备注中保留工商主体 |
| 企业业务描述 | 仅依据原文或公司官网概括，不扩写未经来源支持的业务 |
| 赛道 | 具身智能、航空航天/商业航天/军工、低空经济、汽车及汽车零部件等 |
| 交易轮次 | 天使、种子、Pre-A、A、B、战略融资等，保留原文后缀 |
| 融资金额 | 保留原文单位和模糊表达，如“近亿元”“数千万元”；不擅自换算 |
| 领投方 | 明确写“领投”的机构；联合投资但未指定领投时写“联合投资/未披露单一领投方” |
| 全部投资方 | 仅列原文披露的投资方；“多家机构/上市公司平台”不能虚构具体名称 |
| 资金用途 | 原文披露的用途摘要；没有则写“未披露” |
| 来源链接 | 投资界原文链接，必要时并列第二来源 |
| 核验备注 | 相对日期、赛道边界、金额冲突、重复报道等说明 |

## 纳入标准

- 文章发布日期在用户给定区间内；
- 事件属于企业股权融资或可明确归入一级市场投资；
- 企业主体位于中国大陆，或文章明确说明中国大陆注册/总部；
- 业务与用户指定赛道存在直接关系。

## 排除标准

- 二级市场融资、上市发行、定增、可转债、银行授信；
- 只有订单、采购、战略合作、成立基金或工商注册资本变更；
- 仅作为行业新闻提及、没有融资事件；
- 日期超出区间，除非用户要求按“完成日期”而非“披露日期”筛选。
